# TaskFlow — Gestor de tareas

TaskFlow es una aplicación web de gestión de tareas desarrollada con HTML, CSS y JavaScript. Permite organizar actividades de forma sencilla desde una interfaz oscura y minimalista.

## Funcionalidades

- Crear tareas.
- Editar tareas existentes.
- Marcar tareas como completadas o pendientes.
- Filtrar tareas por estado.
- Eliminar tareas.
- Guardar las tareas en el navegador mediante `localStorage`.
- Diseño adaptable a distintos tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage API
- Visual Studio Code
- Live Server

## Cómo ejecutar el proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar `index.html` con la extensión Live Server.
4. Usar TaskFlow desde el navegador.

## Objetivo

Proyecto personal creado para practicar desarrollo web, manipulación del DOM, eventos de JavaScript, almacenamiento local y diseño responsive.
